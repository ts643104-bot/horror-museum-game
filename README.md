# 🩸💀 دهاليز الرعب والدم — Horror Museum 3D & PWA Game

لعبة ومتحف دهاليز الرعب والدم الافتراضي ثلاثي الأبعاد متعدد اللاعبين في الوقت الفعلي عبر الويب مع إمكانية التثبيت المباشر كتطبيق PWA متكامل على الهواتف والكمبيوتر.

---

## 🎮 مميزات اللعبة

1. **📱 تطبيق PWA قابل للتثبيت**:
   - تثبيت بضغطة زر واحدة على شاشة الموبايل الرئيسية (Android / iOS / PC).
   - شاشة كاملة وبدون أشرطة متصفح مع وضع أفقي تلقائي (`Landscape`).
   - ملف `manifest.json` و `service worker` كاش للأصول.

2. **🎯 منظور وتحكم ببجي موبايل (PUBG Mobile View & Controls)**:
   - منظور الشخص الثالث الكلاسيكي من فوق الكتف الأيمن (TPP Over-the-shoulder).
   - منظور الشخص الأول (FPP) ومنظور تصويب الكتف التكتيكي (Shoulder Aim).
   - مؤشر تصويب احترافي (Red Dot + Crosshair) يتفاعل مع الركض والمشي.
   - حركة واستراد أفقية (Aim-based Strafe) بمحاذاة اتجاه التصويب.
   - أزرار الميلان السريع (Peek / Lean Q & E) لليسار واليمين.

3. **⚙️ تخصيص كامل لمواقع الأزرار (Custom HUD Editor)**:
   - زر إعدادات (⚙️) يتيح للاعب سحب وإفلات أي عنصر تحكم أو زر على الشاشة لحرية كاملة بأصابع اليدين.
   - حفظ الأماكن المخصصة تلقائياً في `localStorage`.
   - زر استعادة الأماكن الافتراضية.

4. **🧟‍♂️ لوحة تحكم الأدمن على الويب (`/admin`) وإدارة الزومبي**:
   - لوحة تحكم حصرية لصاحب اللعبة على المتصفح بكلمة سر.
   - رفع شخصيات ومجسمات الزومبي بصيغة `GLB/GLTF` حتى 40 ميجابايت بضغطة زر وتفعيلها فوراً لجميع اللاعبين.
   - رفع وإدارة براويز وصور القاعات حتى 100 صورة.
   - رفع مجسمات شخصيات الرجال والنساء وحركاتهم.

5. **💀 تحدي كسر اللعنة وميزات الرعب المتعددة**:
   - جمع الجماجم الملعونة الخمس وحل الألغاز الدموية.
   - المصباح اليدوي (F)، مؤشر الرعب ونظام التماسك النفسي (Sanity).
   - محادثة صوتية ودردشة وتعبيرات وحركات تفاعلية في الوقت الحقيقي (Socket.IO).

## 🚀 التشغيل المحلي (Local Setup)

```bash
git clone https://github.com/ts643104-bot/horror-museum-game.git
cd horror-museum-game
npm install
npm start
```

افتح في المتصفح:
- **اللعبة والتطبيق**: `http://localhost:3000`
- **لوحة تحكم الأدمن**: `http://localhost:3000/admin`

## 🌐 النشر المجاني عبر الإنترنت (Online Deployment)

هذا المشروع مبني بـ `Node.js + Express + Socket.IO`، لذلك يمكن نشره مجاناً على أي منصة استضافة تدعم خوادم Node.js و WebSockets مثل:

### 1. النشر على Render.com (موصى به مجاناً):
1. سجل دخولك على [Render.com](https://render.com) بواسطة حساب GitHub.
2. اضغط **New +** ثم اختر **Web Service**.
3. اختر مستودع `horror-museum-game`.
4. املأ الإعدادات:
   - **Environment**: `Node`
   - **Build Command**: `npm install`
   - **Start Command**: `node server.js`
5. اضغط **Create Web Service**.
6. ستحصل على رابط ويب عام للعبة مجاناً (مثال: `https://horror-museum-game.onrender.com`).
7. عند فتح الرابط من الهاتف، سيظهر لك زر **📲 تثبيت اللعبة كتطبيق على هاتفك** فورياً!

### 2. النشر على Railway.app أو Koyeb:
- نفس الخطوات بالربط المباشر مع مستودع GitHub.
