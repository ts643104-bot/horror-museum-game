# 🩸💀 دهاليز الرعب والدم — Horror Museum 3D & PWA Game

لعبة ومتحف دهاليز الرعب والدم الافتراضي ثلاثي الأبعاد متعدد اللاعبين في الوقت الفعلي عبر الويب مع إمكانية التثبيت المباشر كتطبيق PWA متكامل على الهواتف والكمبيوتر.

---

## 🎮 مميزات اللعبة

1. **📱 تطبيق PWA قابل للتثبيت المباشر**:
   - تثبيت بضغطة زر واحدة على شاشة الموبايل الرئيسية (Android / iOS / PC).
   - شاشة كاملة وبدون أشرطة متصفح مع وضع أفقي تلقائي (`Landscape`).
   - ملف `manifest.json` و `service worker` كاش للأصول وأيقونات رسمية.

2. **🎯 منظور وتحكم ببجي موبايل (PUBG Mobile View & Controls)**:
   - منظور الشخص الثالث الكلاسيكي من فوق الكتف الأيمن (TPP Over-the-shoulder).
   - منظور الشخص الأول (FPP) ومنظور تصويب الكتف التكتيكي (Shoulder Aim).
   - مؤشر تصويب احترافي (Red Dot + Crosshair) يتفاعل مع الركض والمشي.
   - حركة واستدارة أفقية (Aim-based Strafe) بمحاذاة اتجاه التصويب.
   - أزرار الميلان السريع (Peek / Lean Q & E) لليسار واليمين.

3. **⚙️ تخصيص كامل لمواقع الأزرار (Custom HUD Editor)**:
   - زر إعدادات (⚙️) يتيح للاعب سحب وإفلات أي عنصر تحكم أو زر على الشاشة لحرية كاملة بأصابع اليدين.
   - حفظ الأماكن المخصصة تلقائياً في `localStorage`.
   - زر استعادة الأماكن الافتراضية.

4. **🧟‍♂️ لوحة تحكم الأدمن على الويب (`/admin`) وإدارة الزومبي**:
   - لوحة تحكم حصرية لصاحب اللعبة على المتصفح بكلمة سر.
   - رفع شخصيات ومجسمات الزومبي بصيغة `GLB/GLTF` حتى 40 ميجابايت بضغطة زر وتفعيلها فوراً لجميع اللاعبين.
   - رفع وإدارة براويز وصور القاعات حتى 100 صورة.
   - رفع مجسمات شخصيات الرجال والنساء وحركاتهم.

5. **💀 تحدي كسر اللعنة وميزات الرعب المتعددة**:
   - جمع الجماجم الملعونة الخمس وحل الألغاز الدموية.
   - المصباح اليدوي (F)، مؤشر الرعب ونظام التماسك النفسي (Sanity).
   - محادثة صوتية ودردشة وتعبيرات وحركات تفاعلية في الوقت الحقيقي (Socket.IO).

## 🚀 التشغيل المحلي الفوري (Local Setup)

```bash
git clone https://github.com/ts643104-bot/horror-museum-game.git
cd horror-museum-game
npm install
npm start
```

افتح في المتصفح:
- **اللعبة وتثبيت التطبيق**: `http://localhost:3000`
- **لوحة تحكم الأدمن**: `http://localhost:3000/admin` *(كلمة السر: `2010`)*

## 🌐 النشر المجاني 100% عبر الإنترنت (بدون فيزا نهائياً)

المنصات التالية تدعم تشغيل Node.js و WebSockets مجاناً تماماً وبدون طلب أي بطاقة بنكية أو فيزا:

### 1. الاستضافة عبر Koyeb (مجاني 100% بدون فيزا):
1. افتح موقع **[Koyeb.com](https://www.koyeb.com)** وسجّل دخولك بحساب GitHub مجاناً بدون فيزا.
2. اضغط **Create App** ثم اختر **GitHub**.
3. اختر مستودع اللعبة: `horror-museum-game`.
4. اترك الإعدادات الافتراضية واضغط **Deploy**.
5. ستحصل فوراً على رابط ويب مباشر مثل: `https://horror-museum-game-xxxx.koyeb.app`.

### 2. الاستضافة المباشرة عبر Glitch.com (مجاني وسهل جداً بدون فيزا):
1. افتح موقع **[Glitch.com](https://glitch.com)** وسجل بـ GitHub.
2. اضغط **New Project** واختر **Import from GitHub**.
3. الصق رابط المستودع: `https://github.com/ts643104-bot/horror-museum-game`.
4. سيعمل السيرفر فورياً ويعطيك رابط ويب شغال مباشرة لك ولأصدقائك.

## 📲 رابط تنزيل وتثبيت التطبيق (PWA):
بمجرد فتح رابط الموقع (محلياً أو أونلاين على الموبايل)، ستجد زراً بارزاً باللون الأخضر في الواجهة الرئيسية:
> **📲 تنزيل وتثبيت التطبيق على جهازك**

عند الضغط عليه:
- على **أندرويد أو الكمبيوتر**: يثبت اللعبة كأيقونة تطبيق رسمي على هاتفك بملء الشاشة وبالوضع الأفقي.
- على **آيفون (iOS)**: يعرض لك نافذة إرشاد سريعة لإضافته بضغطة واحدة إلى شاشتك الرئيسية عبر Safari.
